# Theory sources, and what ANLA takes from them

Seven documents from Neo.K's phase-theory line, copied here because the context
layer's two unbuilt pieces — **relation edges** and the **phase channel** — are the
subject of them. `SegmentIndex.edges` has been reserved and empty since it was
written, and `context_find` reports the phase channel as `ABSENT`. These papers say
what would have to be true before either could honestly be filled.

| file | why it is here |
|---|---|
| `IPFC_Paper01_…_統一接口_…md` | the machinery: identity projection, fibers, transport, lineage factorization |
| `IPFC_Paper02_相位語義_Semantic_Holonomy_…md` | **the directly relevant one** — semantic identity vs semantic phase, and the rejection conditions |
| `IPFC_Paper06_AI_Fork_Theseus_SemanticSplit_…md` | branching identity, which is what a forked or re-segmented archive is |
| `EveMissLab_Phase_Canon_v1.2_…md` | the PH-0…PH-6 type system and the canonical exclusions |
| `Phase_Canon_Audit_Batch04_G4_AI_Search_CrossCarrier_…md` | the audit covering AI, search and cross-carrier claims |
| `ACCR_MCP_ANLA_Contracts_v0.1.md` | names ANLA's tools directly and specifies the read contract above them |
| `ACCR_Technical_Whitepaper_v0.1.md` | the governed-context runtime those contracts belong to |

The extraction — what ANLA may build, and what these papers forbid it from claiming
— is in [`design/phase-and-relations.md`](../../design/phase-and-relations.md).

These are **sources, not ANLA's own documents.** They are Neo.K's, with Aletheia as
co-author on the IPFC series, and they are reproduced unmodified so that what the
design document quotes can be checked against them.
